# ⛪ IBCanoas — Site Institucional

Site institucional desenvolvido para a **Igreja Batista de Canoas (IB Canoas)**, com foco em uma comunicação clara, visual moderno e experiência acolhedora para visitantes e membros.

O projeto foi pensado para transmitir leveza, organização e proximidade, utilizando um design limpo, responsivo e com pequenos detalhes visuais que tornam a navegação mais agradável.

---


## ✨ Funcionalidades

- Página inicial com **hero visual** e identidade moderna
- Seção **Sobre Nós** com informações institucionais
- Informações de **horários de culto** e **endereço**
- Botões de acesso rápido:
  - Nossa História
  - Última Pregação
  - Instagram
- **Agenda de eventos**
- Layout **100% responsivo** (mobile-first)
- Estrutura preparada para expansão futura

---

## 🎨 Design & UX

- Estilo moderno, elegante e limpo
- Uso de ícones para reforçar a leitura visual
- Microinterações sutis em botões
- Hierarquia clara de informações
- Background com profundidade para criar sensação de acolhimento

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript


---

## 📱 Responsividade

O site foi desenvolvido seguindo o conceito **mobile-first**, garantindo uma boa experiência tanto em dispositivos móveis quanto em telas maiores.

---

## 🤝 Projeto voluntário

Este é um **projeto voluntário**, desenvolvido com o objetivo de aplicar conhecimentos em front-end, design e experiência do usuário em um contexto real, atendendo às necessidades da comunidade local.
